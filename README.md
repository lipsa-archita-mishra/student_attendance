# 🏫 Attendance Management System (Streamlit-Python)

A complete, production-quality, beautiful Attendance Management System built entirely in Python using Streamlit. This application features high-fidelity SaaS-style components, secure data processing, interactive analytics, and robust system configurations.

---

## 🌟 Key Features

*   **🔒 Secure Hashing & Session Management**: Uses `bcrypt` (with built-in PBKDF2 fallback) to protect password credentials. Session attributes control access permissions.
*   **📊 Interactive Dashboard (KPIs)**: Metric counters (Total, Present, Absent, Late) styled with premium glassmorphic backgrounds. Also includes a real-time audit event log.
*   **👥 Comprehensive Student CRUD**: Register new students, search profiles, edit details, and upload/replace/delete profile photos (safely stored in a local uploads folder).
*   **📝 Attendance Registry**: Mark daily attendance records using an interactive data grid with built-in status selectors (Present, Absent, Late) and annotations.
*   **📈 Rich Interactive Analytics**: Plotly-powered charts tracking daily turnout trends, overall enrollment distributions, and cross-department comparisons.
*   **💾 Resilient JSON Storage**: All records are saved in atomic JSON flat files. Write procedures use temporary state dumps to prevent data corruption.
*   **📦 Snapshot Backup & Restore**: Compress database snapshots into ZIP archives, manage logs, or roll back data to historical recovery points.
*   **📥 CSV / Excel Data Importer**: Upload spreadsheet templates to register students in bulk, with format validation checks and rejection reporting.
*   **📋 Multi-Format Export Module**: Generate daily, weekly, monthly, or student-specific reports and download them as CSV, Excel, or ReportLab PDF documents.

## 🚀 How to Run locally

### 1. Prerequisite Checks
Ensure Python 3.12+ is installed on your local operating system.

### 2. Dependency Installation
Navigate to your workspace folder and run pip to install dependencies:
```bash
pip install -r requirements.txt
```

### 3. Run the Application
Start the Streamlit application:
```bash
streamlit run app.py
```

### 4. Admin Credentials
Log in with the default administrator account:
*   **Username**: `admin`
*   **Password**: `admin123`
*(Note: Change your password under **My Profile** immediately after first logging in.)*

## 📚 Libraries Used

*   **Streamlit**: Portal layout and core web view widgets.
*   **Streamlit Option Menu**: Elegant navigation sidebar controls.
*   **Pandas & NumPy**: Tabular data manipulation and mathematical checks.
*   **Plotly Express**: Premium, interactive dashboard visualizations.
*   **ReportLab**: Dynamic, print-friendly PDF generation.
*   **OpenPyXL**: Spreadsheet IO reading and writing.
*   **Pillow**: Image formatting and student profile photo cropping.
*   **Loguru**: File logging and runtime warnings tracker.
*   **Pydantic**: JSON input structural schemas.
*   **Bcrypt**: Secure password crypting.

## ☁️ Deploy to GitHub and Streamlit Cloud

1. Create a new empty repository on GitHub.
2. In your project folder, run:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/your-username/your-repo-name.git
   git push -u origin main
   ```
3. Open the GitHub repository and go to the Streamlit Community Cloud deploy page.
4. Choose your repository, select the app entry file as `app.py`, and deploy.

> Important: this app stores its data in JSON files inside the data folder. Keeping those files in the repository helps preserve your current data when you deploy or clone the project.
